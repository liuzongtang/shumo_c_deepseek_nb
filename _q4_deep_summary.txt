===== 问题4 波动电价深化 A/B/C =====
口径：E_MIN=1200、E_INIT=6000；确定性对偶=全年 365 天 LP；费用均报告期 334 天。

【A 鲁棒层储能价值三分解：套利 + 消纳 + 兜底误差】
  完美预见层（无储能 -> 有储能 = 确定性储能价值）：
    同价   ：无储能 1640.73 万 -> 有储能 1222.95 万 = 417.79 万（=套利274.12+消纳143.66，校验差 0.0000 万）
    波动价 ：无储能 1702.68 万 -> 有储能 1278.26 万 = 424.42 万（=套利303.55+消纳120.87，校验差 -0.0000 万）
  鲁棒层（无储能 -> 有储能 = 鲁棒储能价值）：
    同价   ：无储能 2012.85 万 -> 有储能 1472.53 万 = 540.32 万
    波动价 ：无储能 2090.26 万 -> 有储能 1531.51 万 = 558.74 万
  三分解（鲁棒储能价值 = 套利 + 消纳 + 兜底误差）：
    同价   ：套利 274.12 + 消纳 143.66 + 兜底 122.53 = 540.32 万
    波动价 ：套利 303.55 + 消纳 120.87 + 兜底 134.32 = 558.74 万
  兜底误差价值 = 无储能误差代价 - 有储能误差代价：
    同价   ：无储能误差 372.11 - 有储能误差 249.58 = 122.53 万
    波动价 ：无储能误差 387.58 - 有储能误差 253.25 = 134.32 万
  → 波动价下兜底误差价值 134.32 万 vs 同价 122.53 万（+11.79 万）

【B 紧急购电的电价×误差耦合】
  紧急购电量（kWh）：同价 57.57 万 / 波动价 60.06 万（+4.3%）
  紧急购电加权均价（元/kWh）：同价 0.7558 / 波动价 0.7420
  全时段平均电价（元/kWh）：同价 0.7662 / 波动价 0.7575
  → 紧急购电集中在电价 -1.35%（同价）/ -2.05%（波动价）高于全时段均价的时段
  紧急购电费（万元）：同价 217.58 / 波动价 222.82（贵 5.23 万）
  紧急购电日内分布（波动价）：峰值 7:00，清晨 5–7 时占 75.3%（光伏预报偏乐观、谷段电价）
  量×价分解（紧急费 = 量×全时段均价 + 时段选择溢价）：
    同价   ：量贡献 220.57 + 价贡献 -2.98 = 217.58 万
    波动价 ：量贡献 227.49 + 价贡献 -4.67 = 222.82 万
  波动价比同价贵 59 万的结构来源：
    计划费：同价 1254.94 万 -> 波动价 1308.70 万（+53.75 万）
    紧急费：同价 217.58 万 -> 波动价 222.82 万（+5.23 万）
    → 贵 59 万主要来自计划费（跨日价差抬高了计划购电电价），紧急费仅占小头。

【C 跨日套利微小的对偶证明】
  附件4 价差（334 天）：
    日内峰谷差：均值 1.0988 元/kWh（最小 0.8718 / 最大 1.4995）
    日间均价差（相邻天）：均值 0.0614 元/kWh（最小 0.0001 / 最大 0.2528）
    → 日内价差/日间价差 = 17.9 倍（套利主战场是日内峰谷）
  水值 ψ（波动价，334 天）：
    日内波动（每天内 std 均值）：0.2726 元/kWh
    日间均值差异（每天 ψ 均值的 std）：0.1788 元/kWh
    → ψ 日内波动/日间差异 = 1.5 倍（储能的边际价值几乎全来自日内）
  跨日套利价值（确定性层）：每日复位总费 1283.05 万 - 连续总费 1278.26 万 = 4.79 万
    → 允许跨日搬移仅多省 4.79 万，储能价值几乎全部来自日内峰谷套利。
